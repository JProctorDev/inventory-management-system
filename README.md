# Inventory Management System

A Windows Forms inventory management application built with C# and .NET 8. This project demonstrates object-oriented programming, CRUD operations, input validation, data binding, and separation of business logic from the user interface.

## Features

- Add new inventory products
- View products in a DataGridView
- Update existing products
- Delete products with confirmation
- Clear form inputs
- Input validation
- Duplicate SKU prevention
- Automatic inventory value calculation
- Responsive Windows Forms interface
